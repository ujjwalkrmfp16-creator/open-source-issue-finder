# Contributing

Thanks for considering a contribution.

1. Open an issue before large changes and describe the problem.
2. Keep pull requests focused on one change.
3. Add tests for bug fixes and new behavior.
4. Run `pytest -q` before submitting.
5. Use clear commit messages.
6. Never commit secrets, `.env` files, access tokens or personal data.
7. In a pull request, explain what changed, why it changed and how it was tested.

Please be respectful and follow the project's code of conduct and GitHub's community guidelines.
